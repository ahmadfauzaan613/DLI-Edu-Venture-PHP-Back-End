# DLI Edu Venture

Modernisasi backend DLI Edu Venture dengan CodeIgniter 4.7.4, PHP 8.2+, dan PostgreSQL.
Kode aplikasi berada di `app/`, public document root di `public/`, migration schema
di `app/Database/Migrations/`, serta dump MySQL lama dan importer di `database/`.

Konfigurasi lokal disimpan di root `.env` (jangan di-commit). Panduan koneksi PostgreSQL
dan impor data ada di [`docs/database/postgresql.md`](docs/database/postgresql.md).
